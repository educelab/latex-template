\subsection{Analysis Techniques} \label{sec:analysis}
This is a subsection of Methods that introduces how analysis was performed.

Occasionally you will want to have math equations. You can have them
appear inline $F = ma$, or you can have them be block equations:

\begin{equation}
F = ma
\end{equation}

You can do some fun things with equations:
\begin{equation}
\begin{gathered}
E(t) =
\begin{cases}
      1.0-\frac{\beta}{\alpha},& \text{if } \alpha>\beta\\
      1.0-\frac{\alpha}{\beta},& \text{otherwise}
\end{cases}
\end{gathered}
\end{equation}
